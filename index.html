Insurithm AI

An agent that helps fight rejected or delayed health-insurance claims. It reads the rejection letter and the policy, drafts an appeal that cites exact clauses, and stops for a person to approve it.

Problem: appeals fail when they are not tied to the policy wording. Every point in the draft carries a quote from a passage the agent actually retrieved, and a checker drops anything that does not.

15 / 16Policy passages found (baseline: 10)
176Automated tests
0Unsupported claims shipped
  • Python
  • LangGraph
  • MCP
  • FastAPI
  • Gemini
  • SQLite

Key features

  • LangGraph workflow: intake, investigate, draft, verify, human review, finalize. Run state is saved in SQLite, so a review waiting for approval survives a restart.
  • Two real MCP servers (policy search and claim tracking) running as separate processes, with schema validation and access control
  • Citation checker: a point passes only if the cited passage was retrieved, the quote matches word for word, and at least one citation is to the policy itself
  • Compared with a one-shot RAG baseline on 15 synthetic cases: 15 of 16 needed passages found against 10, the same across two runs. Answer accuracy was not clearly better, and the README says so.
  • The comparison exposed two bugs (a cap on evidence in the draft prompt, and citations that rested only on the letter). Both fixed with tests. 176 tests run on Linux and Windows in GitHub Actions.
